# Local Hajin Map Workspace

Opt-in local map viewer, integrated from the owner's original workspace commit `84b793c`. It is separate from the native guide's `/maps/` page and private content packs. Original project code inherits the repository MIT license; game resources are not covered.

From repository root run `npm run map:install`, then `npm run map:dev` and open the printed loopback address (normally http://127.0.0.1:5175/). Use Map key directly for icons and individual/all/none selection; Sources & Layers provides website/category grouping. Selections share browser-local state. Keyboard: arrows pan, +/− zoom, Reset fits the image. Physical-device behavior is not certified.

No game imagery, icons or complete point snapshot are distributed. A fresh checkout intentionally shows recoverable missing-file states. Existing owner-local inputs can be copied into `public/maps/hajin/v1/background.webp` and `public/maps/hajin/official/`. They remain ignored and must not be force-added. Unknown public redistribution permission is not resolved by attribution or local retrieval.

Research acquisition helpers from the original workspace are deliberately not included or run here. This integration reads only owner-supplied local inputs and does not scrape or download source sites. Prepare/review local resources separately and keep them out of public history. Public acquisition tooling, if desired later, requires its own bounded/transactional import design and review.

`npm test` discovers every `tests/*.test.ts` file, including coordinates, bounded inputs and workspace foundation tests. `npm run build` checks types and builds this local viewer. `npm run test:browser` starts an owned local server and uses labeled synthetic records/original pixels, including missing-data and transactional storage recovery. Set `CHROMIUM_PATH` for installed Chromium/Edge or install the package's pinned Playwright Chromium. No real source assets are needed for these tests.

Feature020 adds **My workspace** with My points, Sources, Review, Icons and Backups. It uses a dedicated IndexedDB database, independent of native guide profiles. Map key opens directly and shares source/category visibility and search with Layers. Masters remember category masks; all/none controls work globally and per source.

- **My points:** create POIs, locations and marks by right-clicking the map, numeric coordinates or explicit map picking; preview/cancel, edit/move, delete and undo. Supply applicability, evidence and an ownership declaration. Only point geometry is supported.
- **Icons:** upload owned/authorized PNG/JPEG/WebP, preview sanitized PNG and add a description. Animation and invalid/oversized files are rejected. An annotation icon overrides a category icon, then the built-in fallback. Referenced deletion requires replacement.
- **Sources:** inspect provider links and permission states. Preview an owner-local official capture before importing it. CODMunity, WZStats and CODCentral default to reference-only. An owner-enabled, authorized local capture can provide their layers; no scraper or remote asset fetch ships. Imported files cannot upgrade rights. Unregistered records remain inspectable without guessed placement. Authorized personal backgrounds have their own identity, calibration controls and same-camera opacity comparison.
- **Review:** bounded proximity suggestions never merge automatically. Choose source fields or separately authored evidence, retain alternatives and lineage, accept/withdraw, split or undo. Refresh retains immutable history and flags affected choices stale. Accepted stale entries remain labelled on Reviewed map.
- **Backups:** download a private versioned backup before replacing a workspace. Restore validates/previews the complete graph and commits atomically. Restricted source and derived content is omitted explicitly; authored corrections survive separately. Background pixels are missing dependencies and must be reselected/recalibrated as indicated. Public/share export is unavailable.

A save conflict or quota failure keeps the previous valid state and an exportable draft. Reload saved state or restore the previous revision from Backups; export a failed draft before leaving. Changes made in another tab require reload rather than overwrite. One-time legacy mask migration is previewed and freezes old preferences without deleting them. Closing a workspace dialog does not discard an unfinished form; navigation/undo warns about meaningful unsaved changes.

Storage belongs to the browser and origin, including the port. Export before changing profiles, clearing site data or moving the preview address. Local storage is not a substitute for downloaded backups. No cloud sync or account is involved.

`npm run test:capacity` (root `npm run map:test:capacity`) measures production toggle/search first paint and worker comparison using bounded synthetic fixtures; durable save time is reported separately. On the Windows acceptance host the browser is constrained to four CPU cores and a 512MiB renderer heap. This is not a physical 8GiB-device certification. See [020 evidence and limitations](../../specs/020-map-source-fusion/verification.md).

See the repository's [workspace guide](../../docs/local-map-workspace.md) for boundaries and the [019 specification](../../specs/019-local-map-workspace/spec.md) for integration requirements.

Owner-authorized provider captures are opt-in per machine: set `VITE_LOCAL_PROVIDER_SNAPSHOTS=1` in ignored `.env.development.local` and supply ignored `public/maps/hajin/providers.local.json` plus provider folders under `public/maps/hajin/providers/`. The bounded manifest binds local marker bytes and reviewed affine provenance with SHA256 digests and the canonical background digest. Changed marker/evidence files require renewed capture review; the UI reports failure rather than guessing. A normal checkout remains reference-only. No provider capture or permission declaration is committed.

In Layers, each loaded website has its own master, category masks and Show/Hide buttons. Map key lists its actual category icons. Sources offers **Preview loaded [provider] locations** to stage a capture into immutable review snapshots; accept the reviewed canonical registration explicitly before comparing. Provider verification badges are not our verification, and unknown lineage stays unknown. Right-click opens an unsaved POI draft; a pending edit/preview is preserved and must be saved or cancelled first. In pick-position mode, right-click updates the existing draft position.

Source marker copies now collapse for display across websites. Call of Duty takes priority when selected; otherwise another selected source supplies the marker. Matching uses explicit category aliases and canonical distance/name checks, excludes conflicting known floors/builds, and never groups two records from the same website. `*` matching counts and muted category rows retain all source choices. **Show duplicate markers for comparison** temporarily draws every selected copy; this inspection switch resets on reload. No raw records, notes, review decisions or private points are merged or deleted. Nearby distinct categories/named POIs remain separate. These are likely display matches, not factual equivalence or independent verification.
