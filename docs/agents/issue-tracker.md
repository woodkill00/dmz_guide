# Task authority

This project's default tracker is the existing selected specs/<feature>/spec.md, plan.md and tasks.md. Analysis reports findings; implementation repairs owning artifacts, reruns analysis and later convergence. Reviewer checklists stay reviewer-owned. This is a pointer contract, not a new scratch issue queue.

GitHub issues/PRs may mirror the work when the user actually authorizes those writes; preserve links to canonical requirement/task IDs. Use the existing .github/pull_request_template.md. Do not publish/close issues, add labels or change repository settings merely because an upstream skill normally does so. No credentials or external tracker setup are needed to use the local helpers.
