# Missions directory and editing

Open [Missions](http://127.0.0.1:4173/missions/?pack=official%3Amw4-dmz-starter) for the Hajin and X01 Orders directories. Hajin shows all 24 slots, with three source-reported mission rows per page. The seven fixed page rosters have direct page evidence; chapter choices can change the other page numbers in game, so match a chapter and Order name before relying on a position. X01 has its own five-page list, separate from Hajin page numbers. The lists describe catalog content, not your completed progress.

Selecting a mission opens its individual objective page. **Edit mission content in Content Studio** opens the exact record in the local repository editor at `http://127.0.0.1:4174/`. Start it with `npm run author` in the checkout if the link is unavailable. Review guided fields and sources, then explicitly save repository files and rebuild the guide. This does not change your private inventory or mark a mission complete. The existing guidance page remains available as **Editor setup**.

**Audit this mission** opens the matching identity section in [Mission audit](http://127.0.0.1:4173/missions/audit/). The audit has separate Hajin and X01 page lists. Its mission links open the pack-bound local reader so a private edit or added mission cannot be confused with an older public page. Audit notes and section states are private editorial work, separate from published mission facts. Existing Hajin audit IDs and version-one backups remain valid.

X01 records contain 15 short, paraphrased task summaries from [COD Central](https://codcentral.net/blog/mw4-dmz-orders/) and [DMZ Codex](https://dmzcodex.com/guides/x01-orders-guide/). The five X01 chapter reward lists are also shown as COD Central reports, checked 2026-11-16. Item costs, unlock effects and current-build behavior remain unverified. Six Hajin Story Mission rows stay hidden until spoilers are enabled in the private profile. Source-reported placement and player completion must be checked against the user's actual game screen.

## Mission tasks and page rewards

Individual mission pages now display each catalogued task step, with an explicit review message when steps are missing. A link returns to its page in the mission directory, and another opens its exact audit target. Seventeen Orders include a **Guide pictures** gallery with 26 locally bundled COD Central screenshots; open a picture for a larger view or follow its source link. The project owner asserted permission to redistribute these screenshots in the public repository. Pages without a source screenshot keep their text and source-chapter links. Short location notes appear where recorded. Source-reported Hajin and X01 page rewards are in a compact **Reported page rewards** disclosure on both directory and detail pages. These are rewards for finishing the page, not grants from a single Order; they do not change inventory or progress.

Hajin reward names were cross-checked against [COD Central](https://codcentral.net/blog/mw4-dmz-orders/) and [DMZ Radar](https://dmzradar.com/orders.html), with [Game8](https://game8.co/games/Call-of-Duty-Modern-Warfare-4/archives/632467) used where its work-in-progress guide covers the chapter, on 2026-11-14. X01 rewards follow COD Central's X01 chapters as reviewed 2026-11-16. Some community reports disagree on quantities, so disputed quantities are omitted. All reward claims remain unverified for the current game build. The reward lists follow chapter rosters when chapter page placement varies. See the [87-entry source audit](../specs/085-codcentral-order-completion/source-audit.md) for the identity and task-presence check.
