# Missions directory and editing

Open [Missions](http://127.0.0.1:4173/missions/?pack=official%3Amw4-dmz-starter) for the Hajin and X01 Orders directories. Hajin shows all 24 slots, with three source-reported mission rows per page. The seven fixed page rosters have direct page evidence; chapter choices can change the other page numbers in game, so match a chapter and Order name before relying on a position. X01 has its own five-page list, separate from Hajin page numbers. The lists describe catalog content, not your completed progress.

Selecting a mission opens its individual objective page. **Edit mission content in Content Studio** opens the exact record in the local repository editor at `http://127.0.0.1:4174/`. Start it with `npm run author` in the checkout if the link is unavailable. Review guided fields and sources, then explicitly save repository files and rebuild the guide. This does not change your private inventory or mark a mission complete. The existing guidance page remains available as **Editor setup**.

**Audit this mission** opens the matching identity section in [Mission audit](http://127.0.0.1:4173/missions/audit/). The audit has separate Hajin and X01 page lists. Its mission links open the pack-bound local reader so a private edit or added mission cannot be confused with an older public page. Audit notes and section states are private editorial work, separate from published mission facts. Existing Hajin audit IDs and version-one backups remain valid.

X01 records contain 15 short, paraphrased task summaries from [COD Central](https://codcentral.net/blog/mw4-dmz-orders/) and [DMZ Codex](https://dmzcodex.com/guides/x01-orders-guide/), checked 2026-11-14. Rewards, item costs, unlock effects and current-build behavior remain unverified. Six Hajin Story Mission rows stay hidden until spoilers are enabled in the private profile. Source-reported placement and player completion must be checked against the user's actual game screen.
