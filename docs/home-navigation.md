# Home, navigation and verified workflows

Open [Home](http://127.0.0.1:4173/) for your field desk. The guide remains local; the companion map, Content Studio and update manager run separately.

## Find the next task

The main navigation is Home, Map, Prepare, Track, Reference and Manage. Search opens the unified public index. More groups every remaining destination by task and offers a menu filter; All features is the full searchable directory. Native links and disclosure menus work without JavaScript. Escape closes an open menu and restores focus; outside clicks/focus also dismiss it. Breadcrumbs identify the workspace and detail page.

There are76 registered destinations, including every prior map tool. Map tools open the companion explicitly. Within the map, plain tool-menu clicks and the workflow toolbar open the existing tool without reloading; modified clicks retain normal browser behavior. Existing dirty-draft guards still control departure/tool changes.

## Your home dashboard

Open map and Continue provide direct entry. Pin up to eight tools from cards/All features. Recent work records up to eight workspace IDs, not document names, full URLs or private notes. Display preferences live under `dmz-navigation-v1`; denied storage leaves session-only shortcuts with a visible message.

Choose a catalog to read its existing saved profile. Summaries are read-only snapshots with a revision and catalog-version check, strict spoiler protection and legacy progress interpretation. Unknown, missing, old, malformed, blocked or timed-out data is labeled rather than treated as completed or zero. A catalog with no safely visible definitions reports unknown coverage. Keys remain a separate saved workspace. Home summary reads do not initialize profiles or synchronize application databases.

Refresh summaries reads again. Check services is explicit: it checks only the four fixed loopback service origins, with deadlines. Reachable means transport reachability, not certified app health; unavailable can also mean browser policy blocked it. It does not launch services or fetch providers.

## Search and return

Search covers safe public catalog records, keys and grids, weapons, attachments and feature tools. Fictional packs, spoiler records/protected terms and private profiles/notes are excluded. Missions, upgrades and other progression records retain separate types. Map workspace content has its own linked search.

Search results open exact detail pages and relevant existing collection or key-trip workspaces. Grid links show reported areas, never invented door pins. Public-index coverage limits are visible if the bounded index cannot include every eligible record. No match does not prove a game record does not exist. Home query transfer uses bounded session storage instead of adding typed text to the URL. Ctrl/Command+K and the visible Search link open search.

Back to results restores bounded allowlisted public filters, sorting, group expansion and scroll within the same catalog/version. Existing dedicated view preferences retain ownership. Any user interaction prevents delayed restoration from replacing newer choices. Browser Back, reload and cached-page resume are tested; unavailable session storage leaves normal navigation usable. Private notes/stock editors are not copied into list context.

## Map workflow tools

The map toolbar exposes Search, Layers, Routes and Trackers. Advanced retains source review/update impact, backups and Reset panel layout. The selected-location inspector displays inert bounded text from the current popup, highlights the marker, minimizes/expands and offers keyboard-accessible size sliders. Closing a popup clears its selection; closing/minimizing the summary never changes records. Layout reset changes display preferences only. Existing draggable menus and route tracking remain intact.
