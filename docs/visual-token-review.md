# Measured token contrast, not a UI conformance claim

The accompanying token-contrast-check.json records opaque solid-color luminance calculations. This is the one executed numerical design check in this pack, not application tests or rendered WCAG conformance. Text on alternate surface is 12.8:1; secondary text 8.3:1; gold on alternate 7.65:1; lime 9.58:1. Decoration #526164 is only 2.26-2.87:1 against the proposed surfaces: do not use it for essential boundaries or text. Off-white text on gold (1.67:1) or lime (1.34:1) fails normal text contrast; use dark canvas text (9.70:1 on gold, 12.14:1 on lime). Cyan focus against gold is 1.03:1, and white against gold 1.67:1: neither is a sufficient standalone focus ring. Use a dark offset plus outer light ring against adjacent dark surfaces, then test actual rendered focus, hover, disabled, selected and error states. Transparency, images, gradients, typography and overlapping surfaces need separate measurement.
