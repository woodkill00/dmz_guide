1. Whether MW4 DMZ stash, carried equipment, upgrades and Orders/progress are available to approved integrations, and which exact fields are supported.
2. The eligibility and approval process for a personal, local-use integration, including any commercial or organizational requirements.
3. The supported authentication and player-consent flow, documentation, scopes, rate limits and data-retention requirements.
4. Whether a one-time player data export is available if live API access is not offered, and whether it includes those DMZ fields.

I can provide a project overview or repository URL if the receiving team needs one.
