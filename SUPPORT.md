# Getting help

This is a community project in bootstrap, not an official game support channel. No live app, Discord destination, support mailbox or response-time commitment is established.

For ordinary questions, check the [documentation index](docs/README.md) first. Use this repository's GitHub Issues for a sanitized project question or reproducible non-security bug if Issues are available. Describe what you tried, the relevant document/commit, expected result and actual result. Do not attach private exports or account information.

For game account, billing or platform issues, use the relevant official service's support route; this project cannot access or recover accounts. For vulnerabilities, use [SECURITY.md](SECURITY.md).
