# dmz-write-agents

Read the [project workflow bridge](../../../docs/agents/workflows.md) for authority, scope, task selection and evidence rules. Consult only the relevant [repository map](../../../docs/agents/repository-map.md) and [domain guide](../../../docs/agents/domain.md).

Keep instructions that change decisions or preserve a non-obvious invariant. Put common actions in the entry point and conditional detail behind labeled links. Reuse existing authority instead of repeating policy, scripts or task state. Use meaningful completion criteria and narrow descriptions so unrelated work does not trigger the helper. Preserve privacy, authorization and reviewer ownership when shortening text. Validate names, metadata and references after edits; exercise the changed instructions with a realistic task before claiming behavioral improvement.

[Original source](../../../vendor/agent-skills/mattpocock/writing-for-agents/SKILL.md) is optional historical reference. This local adaptation is the operative procedure; do not inherit extra interview, publication or tool prerequisites from the original.
