# dmz-retro

Read the [project workflow bridge](../../../docs/agents/workflows.md) for authority, scope, task selection and evidence rules. Consult only the relevant [repository map](../../../docs/agents/repository-map.md) and [domain guide](../../../docs/agents/domain.md).

Use actual session evidence: failed commands, repeated investigation, missing context and successful reproductions. Check existing scripts/CI before proposing another check. Prefer a deterministic guard for a mechanical error and a concise pointer for a navigation problem. Separate recommendations from approved changes; scope any implementation to the current task. Do not add universal policy for one isolated example. Record the most consequential supported improvement, its expected benefit and how to verify it. A proposal is not a completed change.
