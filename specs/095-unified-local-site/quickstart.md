# Unified local use

`npm run local` or `scripts\start-local.cmd` serves guide and maps at http://127.0.0.1:4173/. Maps: `/map/`, `/map/x01/`, `/map/safes/`, `/map/loot/`. Author remains optional4174 via `npm run author`. `npm run local -- --skip-build` requires current validated map artifacts and an existing guide build. See [startup and migration](../../docs/unified-local-site.md).

Old5175 data stays in its browser/profile. `/map/migrate/` provides explicit legacy startup/export/validated restore instructions and supplementary preference review. Do not Reset to find old data. Public asset distribution is excluded. The user subsequently authorized committing and merging the completed work.
