# Contracts and caps
Fixed providers: official, codmunity,wzstats,codcentral. Existing5000records/100categories/source, snapshot2MiB and workspace20MiB/20snapshots/20000retained records still apply. Network: HTTPS allowlisted host/path only, manual checked redirects<=2,15s/request,4MiB HTML/JSON (then snapshot2MiB),8MiB official bundle,32MiB comparison image,512KiB/icon and4MiB icons/source,270 official /128 provider requests and64MiB/source,180s job. Reject blocked requests and unexpected/empty schemas rather than guessing.

At most two ready/reserved jobs per server,15min expiry for unreserved previews, reserved jobs persist for recovery, and one collector per server at a time. API bodies<=4KiB, job IDs UUID only, random server token. Job {id,status,basePointerDigest,sourceOutcomes,captureDescriptors,startedAt,expiresAt}; outcomes include added/changed/missing/category changes,unchanged/updated/error/frame-review state and icon warnings. Stage assets under ignored public/maps/hajin/captures/<job>/<source>/; pointer current-captures.local.json contains fixed source IDs, safe relative paths and SHA256 bindings. Existing v1 local captures remain readable. Private authorization/registration metadata is never committed.

Workspace canonical snapshots are adapted with stable semantic identity; compare current records by source ID+record ID, retain prior snapshots and mark affected decisions stale. Reuse existing equal semantic snapshots, including retries. File activation CAS checks base pointer under lock; rollback pointer retained. No physical source mutation before Apply. Browser/storage and server/files cannot be one transaction: activation retry is explicit and idempotent.


Recovery contract: before a workspace commit, reserve the ready job on disk and save a localStorage receipt with job ID, target snapshot keys/digests and fixed local descriptors. Failure to persist the receipt blocks the workspace commit. Reserved jobs survive server restart and do not expire; at most two ready/reserved jobs may exist. On resume, compare every receipt key/digest to the workspace: all present allows activation retry without import, otherwise dismiss and recheck. Cancellation before commit leaves both active stores unchanged. After commit, dismissal cancels only file activation and retains the committed workspace; a fresh check reconciles it. Pointer CAS conflicts never overwrite the competing pointer. The first phase can succeed alone and is labelled pending, not fully applied.

Parser isolation: JavaScript-disabled fresh blank browser context, service workers blocked, all HTTP/file/navigation/resource routes and WebSockets denied. HTML is parsed only into detached DOMParser documents, never navigated or set as page content. Calls, functions, prototype keys and cycles in hydration values are rejected, never evaluated.

Semantic projection: sorted category IDs including name/group and exact sanitized icon byte SHA256; sorted record IDs including category/name/normalized canonical coordinates (rounded to1e-9 normalized units), notes and known floor. Map ID/coordinate version and canonical image digest are fixed validated contract fields. Capture timestamp, JSON object/array order and generation/icon paths are excluded. A changed payload under a stable upstream ID is a changed record, not another location; duplicate IDs within a feed fail. Icon-only and note-only changes create a new capture; reordered equivalent captures reuse old data. Private metadata remains bound to its original immutable capture.

Official image verification checks all256 reviewed zoom4 tiles with at most8 concurrent requests (270 total requests allowed for official,128 for each provider). A changed tile or provider image pauses that source. Staged job bookkeeping is capped at64 jobs per local installation; reaching it requires explicit local maintenance instead of unbounded staging. Committed generations are retained because workspace evidence can reference them.

All reserve/cancel/activate transitions share the filesystem lock and reread persisted job state under that lock. If another transition owns the lock, cancellation fails explicitly instead of claiming cancellation. After a crash, stop all map servers before removing the exact ignored update.lock file; no automatic stale-lock reclamation risks stealing a live lock. Ready-job listings and capacity checks reread durable state across server instances. Equivalent absent/null floors and absent/empty notes hash equally.
