# Built-in specification quality checklist

Maintained by specify/clarify, 2026-10-26. Artifact-quality assessment only; not independent review or runtime acceptance.

- [x] Prioritized stories have independent checkpoints and acceptance scenarios.
- [x] Observable requirements are testable, scoped and separated from technical design.
- [x] Measurable outcomes distinguish target acceptance from performed checks.
- [x] Edge cases include uncertainty, state recovery, privacy, compatibility and accessibility.
- [x] Unknown game facts have explicit blocked behavior rather than guessed answers or unresolved architecture placeholders.
- [x] No implementation, merged catalog, current-build verification or exhaustive coverage is claimed.
- [x] Requirements trace to future tasks and acceptance evidence.

Gameplay confirmation gates remain open by design; this checklist does not certify them. Independent definition review is in `upgrade-planning.md`; its boxes are reviewer-owned.
