# Validate and use

Run npm run skills:check, npm run skills:list and npm run test:skills from the checkout on PowerShell or Linux. Run the skill creator checker on changed helper frontmatter.

Run npm run skills:pilots for the OS-temp fixture path. Give a fresh agent one raw request and its sources plus installed helper paths, withholding expected oracle answers. Another actor reviews standards/spec and resumes from the handoff. Record actual observations in [evidence](evidence/README.md); generation alone is setup.

Read [workflows](../../docs/agents/workflows.md) for invocation, feature selection, update/rollback and direct-path versus session discovery. No private profile or credentials required.
