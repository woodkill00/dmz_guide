# Research and decisions

Reviewed [upstream commit](https://github.com/mattpocock/skills/tree/6f7f7831a625f040a8e06a0e7954826b87ce775a), plugin manifest 1.3.2 and root MIT license. Review is not execution.

| Decision | Rationale | Alternative |
| --- | --- | --- |
| Twelve adapters plus inert complete selected source folders | Inspectable lineage and precise discovery | Global automatic updates bypass review |
| Preserve ten official helpers and lock | Existing provenance gate remains authoritative | Editing upstream invalidates pins |
| Specs/tasks as tracker | One delivery authority | Duplicate scratch/GitHub queues imply extra writes |
| Approved plan defines test boundaries | Routine authorized autonomy | Repeated seam approval adds friction |
| Bounded independent review | Separate standards/spec findings; safe outputs | Unbounded implementation orchestration is deferred |
| Node-only local tooling | Windows/Linux, no new dependency or CDN | Bash/global plugin/report assumptions complicate setup |

Selected originals: diagnosing-bugs, tdd, code-review, domain-modeling, writing-for-agents, handoff, retro, research, prototype, codebase-design, improve-codebase-architecture, pr. Complete folders and their references/credits are retained. Local entry points do not require unselected skill invocation.

Deferred: standalone to-spec/to-tickets/implement/implement-spec orchestration; triage/wayfinder issue publication; credential wizard/teaching; in-progress and unmaintained misc. These are explicit exclusions, not missing approved work. Existing user decisions resolve all blocking ambiguities.
