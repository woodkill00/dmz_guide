# Data model
FieldGuide.toolkit optional: version1, missions<=20 (id/name, objectives<=32: id/text/done/waypoint|null), collections<=30(id/name/members<=100Waypoints/visible), routePrefs<=20(routeId/avoidedEdges<=1000/visible), trash<=20Annotations <=2MiB. Every object exact-key validated; IDs unique; waypoint validation reuses existing FieldGuide rules, identity source+capture-bound. No reference requires copying provider content. Deleting a route removes its prefs. Trashed annotations retain referenced owned icons and screenshots and count against global asset limits.

Annotation optional metadata exact object: tags<=20unique nonempty40chars, building<=120, approach<=2000,lastChecked realYYYY-MM-DD or empty. Existing annotation fields/attachments unchanged.
Pack kind dmz-map-selection version1: routes<=20,missions<=20,collections<=30,points<=500,icons<=32 (only references from points). <=8MiB strict JSON before allocation, validate all owned assets and reference endpoints. No snapshots, road graphs, basemaps, private tracking or trash. Preview computes semantic matches ignoring IDs; remaps colliding IDs and custom references in a projected clone. Repeated unchanged import is no-op. Changes require explicit apply against captured revision; conflicts/quota preserve old workspace.
Session marks<=100 coordinate/type/label, measurement<=100 vertices kept in memory/tab only; exclude backups/packs. Settings are local display preferences except existing persisted gameplay choice.

Clarifications: trash2MiB counts UTF-8 serialized annotations including inline screenshots, and retains icon dependencies in normal library; all screenshot/icon/global limits include trash. Delete blocks on full bin; explicit permanent-delete is offered. Undo restores the store’s immediately preceding committed whole-workspace snapshot, reversible until another commit replaces the pair; no session history claim. Avoidance binds SHA-256 of exact validated graph JSON, never raw edge ID alone; graph mismatch disables avoidance with explanation, no silent application. Pack screenshots included only for selected owned points and counted in8MiB; custom/reviewed location references without an owned included point stay unresolved, explicitly reported; reviewed content itself never copied. Semantic fingerprints omit local IDs/timestamps, include authored content and ordered waypoint identities (source keys/capture and remapped owned content), exact repeats reuse IDs while changed content adds a new object. Packs do not overwrite old objects. Imported record handles preserve stale capture identities. Session marks max100,label<=100, in memory for current tab page lifetime (reload clears); no storage.
