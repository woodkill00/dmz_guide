# Fluid UI/UX redesign planning package

Status: proposal and isolated concept only, 2026-11-05. Existing runtime on main1acf2a8 is unchanged. Manual pinned Spec Kit v1.2.2 planning/documentation cycle; no claim of skill execution or shipped redesign.

User objective: a complete, modern, unobtrusive and fluid interface across the local guide, map, catalogs and management tools. Explicit authorization includes online research, multiple design-agent reviews and a roundtable. Deliver an audited proposal, researched decisions/pros/cons, interactive illustrative concept, phased implementation backlog and verification gates. Runtime implementation is a subsequent feature sequence.

FR001: one canonical five-hub hierarchy Home/Map/DMZ Guide/DMZ FOB/DMZ Weapons; Search and Tools/settings utilities. Existing URLs, tool deep links and feature reachability remain mapped. FR002: layout-owned shell, contextual task navigation and one main task/detail pane remove collisions; reserved route status slot is the limited persistent exception. FR003: preserve no-autopan selection, explicit Locate, source/category/dedup controls, view context, stable counters and dirty-draft guards. FR004: responsive dark/light semantic tokens and readable compact/comfortable density; mobile explicit sheet/page states and accessible non-gesture alternatives. FR005: shared list/filter/detail and feedback patterns retain unknown/source/build/mode labels, verification/provenance and local-data boundaries. FR006: reversible phased rollout, exact preservation tests, measurable layout goals and honest prototype/research limitations. FR007: research sources and three actual agent positions, disagreements and negotiated resolutions are recorded. FR008: isolated concept visually communicates Home, Map, Guide, FOB and Weapons without owner assets/private data/game facts; demonstrate interaction hierarchy, not simulate existing real functionality.

Clarifications resolved through existing user direction and audit: canonical hubs follow the user's previously requested hierarchy; modern means restrained opaque surfaces and clear typography, not glass/neon. Compact means less repetition/spacing, not tiny text. Services/data remain separate. No global rewrite or new library is assumed. Owner visual preference and real-player usability observations remain validation work, not a blocker to this proposal.

Owning artifacts: docs/ui-ux-redesign.md (reviewable plan); research.md; roundtable.md; plan.md; tasks.md; prototype/index.html; checklists/review.md (independent reviewer ownership). No production assets/content/state changes.
