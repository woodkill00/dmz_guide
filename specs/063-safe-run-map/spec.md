# 063 Safe-run map

Manual pinned Spec Kit v1.2.2 full cycle. User requests a separate map page highlighting safes, selectable spawn, selected/excluded safes, editable order and efficient routes. Existing main map and private workspace stay authoritative and unchanged.

- FR001 Dedicated /safes.html companion page, shared navigation/feature directory/mindmap entry. Reuse canonical background/grid, keyboard zoom/pan and source captures, not another copy of game assets.
- FR002 Load bounded, validated same-origin current captures, verify available snapshot digests; fall back to reviewed local manifest when no current pointer exists. Display all positioned safe-category records and spawn points from those captures, source attribution/capture date, unknown/live-match caveat and explicit load failures. Never plot reference-only unregistered positions. Conservative shared name+coordinate+floor display grouping retains evidence; ambiguous nearby records remain separate and can be excluded manually. No fabricated safes/spawns/completeness.
- FR003 Choose reported spawn or click/right-click terrain to set manual start, with accessible numeric X/Y controls. Every safe has a checkbox and focus-on-map action; all/none and search are available. Filtering never silently changes selection. Numbers reflect visit order. Manual drag reorder plus keyboard move up/down. Recalculate when start/selection/mode changes; manually reordered sequence stays manual until Optimize.
- FR004 Open route from spawn through selected safes, no forced return. Direct mode uses straight-line pixel distance, expressly not traversable roads. Road mode uses existing validated local graph, directed shortest paths with off-road connectors; missing legs shown as missing, never silently bridged as roads. Efficient automatic order uses deterministic nearest-neighbor heuristic with bounded work, not global optimum, game meters, travel time or live guidance. Cap candidate stops and graph computations explicitly, no silent data truncation. Async worker prevents blocking; stale results ignored/cancelled.
- FR005 Separate versioned bounded local preference only, no existing workspace mutations. Storage failure/malformed state must leave page usable and visibly report persistence failure. Reload retains exclusions/order/start/mode when valid; changed capture reconciles removed/new IDs visibly. State writes contain IDs/order/start, not imported notes/assets. No remote acquisition, accounts or publication.
- FR006 Verify pure validation/grouping/ordering/directed paths/limits, real three-engine selection/spawn/order/reload/failure/race/mobile/keyboard/axe flows; existing map regressions/build and guide registry/build/check. Independent definition and final review, exact acceptance evidence and documented limits.

Clarifications resolved by existing architecture: spawn may be source point or manual terrain selection; safest default is direct planning with explicit limitation because local road graph has only 11 segments and is unverified. All means all positioned source-reported safe candidates, not certified in-game completeness. Persistent main-map source filters do not hide candidates on this page.
