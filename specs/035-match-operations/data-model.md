# Data model
Operations(version1,activeSessionId:null|id,sessions<=20,roadChecks<=1000). Session(id,name<=100,date realYYYY-MM-DD,startedAt ISO,endedAt ISO|null,routes<=10 captured PlannedRoutes,missionIds<=20,objectives<=64 snapshots {missionId,objectiveId,text<=300,done,waypoint|null},marks<=100 {id,type:note/danger/rally,label<=100,x/y},entries<=100 {id,at,text<=2000,waypoint|null},notes<=4000,checklist exactly10 {id,result:not-tested/pass/fail,notes<=1000}). Unique IDs, active pointer resolves a non-ended session; only one non-ended session. Snapshots contain source handles/private manual coordinates only, never provider content. Source refs pinned in backup/pruning. RoadCheck(id,graphSignatureSHA256,edgeId<=128,kind:road/junction/bridge/gate,date,status,notes<=2000,attested:boolean); authoritative-status reports require attestation+date+notes. Reports do not change graph or game truth.
No raw imported backup/source data saved in preview. Comparison rows bounded by admitted counts and paginated; last download receipt read via existing local guarded metadata. Optional operations validated inside FieldGuide; no automatic migration on read. Source impact scan uses before/after stable IDs and exact capture-bound references in current entities; historical sessions read-only.

Clarifications: route snapshots are wrappers {id,at,route:PlannedRoute}, allowing multiple explicit captured versions of one route without overwriting history. objectives is frozen start snapshot; endObjectives is null while active and separate snapshot on end, with missingMissionIds listing selected missions no longer available. Journal shows current live mission progress without mutating start snapshot; completion editing uses exact Mission editor. Explicit Record active route appends a distinct snapshot, at most10. No automatic rewriting of prior captures.
Operations additionally has rebindings<=1000 {id,at,key,fromIdentity,toIdentity,tracking:Tracking|null}. Rebinding tracking archives its exact old observation here, resets current confidence to unverified,date/evidence empty,visited/checked false,revisit true,retains favorite. Confirmation explains this reset; archive retains old source dependency and evidence, with explicit delete/export controls. At limit refuse rather than discard history. Routes remove old reached token; missions/collections only replace selected handle. Closed session references cannot be rebound.

Explicit source-stop replacement requires a new owner-picked map position and generic manual label, never copying provider coordinates/title into a manual exported stop. Dragging does not convert source references.
