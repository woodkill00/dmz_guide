All object keys exact; JSON depth/node/workspace20MiB admission unchanged. IDs are nonempty strings<=128; owner labels trim-nonempty; ISO timestamps must roundtrip through toISOString. SHA256 lowercase64hex. All arrays enforce unique IDs and reject overflow, never trim.

Command={version:1,matchMode:boolean,presets:Preset[],links:Relationship[],promoted:Promotion[],avoidances:Avoidance[],captures:Capture[],progress:Progress[]} optional on FieldGuide; no mutation on read.

Panel IDs only existing layout allowlist. Visibility validated with existing private backup validator: known source IDs,<=100 category flags/source, booleans/query<=256. Apply staged visibility/gameplay inside existing workspace transaction/CAS; only after success set map center/zoom/panel positions and local display preference. Failed quota/CAS leaves all display state untouched. Unknown/unavailable categories removed from applied mask with notice; preset retained unchanged, never enables nonexistent data. Panel changes dispatched through layout event, clamp to current viewport.
Relationship={id,type:entrance|exit|floor|key|objective,label<=200,from:Waypoint,to:Waypoint};<=500. Both validated exact source handles/manual positions. Display stale endpoints without silently updating. Pins all source handles.
Promotion={sessionId,markId};<=1000 unique pairs. Only actual session/manual mark can be promoted, commit POI+receipt atomically. Delete session does not erase receipt; receipt explicit export/delete available only with warning that removing it permits another promotion.
Avoidance={routeId,graphSignature,areas:[{id,x1,y1,x2,y2}]};<=20 routes,<=20 areas/route; bounds0..4096 and strict x1<x2,y1<y2. Inclusive segment/rectangle intersection rejects every intersecting graph edge. Stale signature refuses solve, explicit reset required. Existing route-edge exclusions compose with rectangles.

Capture pack={kind:'dmz-reference-capture',version:1,sourceId,sourceURL,capturedAt,digest,extractor:'html-candidates-v1',records:Candidate[]}. SourceID/URL must match researched registry entry exactly (HTTPS no credentials/query/hash); no imported arbitrary provider. Candidate={id,kind:item|upgrade|weapon|attachment|material|recipe|mission|order|story|reference,title<=200,summary<=600,url<=2048,build:string<=100|null,spoiler:boolean,digest}. Candidate URL same registry origin and admitted provider section path, no executable schemes. All strings nonempty except summary. Candidate IDs unique within capture;<=2000. Record digest SHA256 canonical JSON array[id,kind,title,summary,url,build,spoiler], independent of page capture time/hash. Capture digest raw response bytes. Import recomputes candidate digests, rejects mismatches. Page hash is provenance, not verification.
StableID=SHA256 canonical JSON array[provider detail URL/fragment,kind,build] where available; anchorless heading uses SHA256 canonical array[pageURL+'heading:'+normalizedheading,kind,build]. Heading rename without stable anchor intentionally becomes remove/add, never inherits old completion. Repeated links dedup exactID; no fuzzy merging. Different kinds/builds retain separate records; cross-provider normalizedtitle/kind/build only a comparison grouping with all provenance.
Command.captures retain actual prior candidate versions, not just receipts:<=80 captures total,<=20/provider and<=10000 candidate occurrences across ALL retained captures (including history); finalworkspace20MiB. Same sourceID+page digest is idempotent no-op. Changed page with identical candidate digest preserves progress. Most recent capturedAt perprovider is current; older imports rejected unless exact already-retained no-op. Source removes are inferred from missing stableIDs between two captures and remain accessible in history, no automatic deletion. Owner exports private backup then explicitly removes selected old capture at capacity, with warning if historical progress depends on it; no automatic history pruning.
Progress={sourceId,recordId,recordDigest,selected:boolean,done:boolean,notes<=2000,updatedAt};<=2000 unique sourceID/recordID pairs, source/record must exist in retained captures. Current digest mismatch shows stale status, requires explicit confirmation/review before user updates completion; refresh never transfers it. Delete capture refused if it is sole provenance for saved progress; remove progress explicitly first. Catalog rows resolve current plus historical/missing, filtered/paged25; spoilers hidden by default and search does not leak hidden text. Public views/selection packs omit all Command data; private backup includes it.

No homepage slash wildcard. Fragments permitted for stable anchors, query strings removed by collector and rejected on import. Fetch URLs remain EXACT registry URL only; candidate links are never automatically crawled.
