Retained tools: global max retained floor for relevant goals; protect that stock before consumed allocation. If same item is tool+ingredient, owned stock must satisfy both. Retained-only demand never triggers consumed batches unless explicitly crafted to supply missing tool.

Strict priority blocks stock reserved by higher-priority demand; work-conserving skips blocked goals and can use it. Do not equate aggregate requirements with feasibility.
