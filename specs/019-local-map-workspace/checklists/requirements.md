# Specification Quality Checklist

Built-in specify/clarify review, 2026-10-26.

- [x] Users and additive scope are explicit.
- [x] Stories have observable acceptance scenarios.
- [x] Requirements and success criteria are testable.
- [x] Missing files, invalid data, storage failure and source isolation are covered.
- [x] Rights/privacy/publication boundaries are explicit.
- [x] No unresolved clarification markers remain.

Custom reviewer-owned criteria are separate from this built-in checklist.
