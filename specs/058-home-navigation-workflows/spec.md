# 058 Home dashboard and unified navigation

The user authorizes the six improvements proposed after057, with dedicated upgrade and mission verification journeys. Local-only work, no provider collection, game changes, publication or progress migration.

FR001 Home becomes an actionable field desk: unified search, Open map, Continue planning, grouped feature shortcuts, bounded pinned/recent destinations, and truthful read-only private progress summaries. Missing/unavailable data is never zero/completed. No private notes, spoilers or profile contents enter URLs or public search.
FR002 Shared Home/Map/Prepare/Track/Reference/Manage navigation, active category/page, breadcrumbs and searchable All features. Every existing guide/map tool remains reachable from one registry; separate applications/new tabs are explicit. Native links work without JavaScript; Escape/outside/focus dismissal and narrow layouts remain accessible.
FR003 Unified search route indexes public nonspoiler catalog, keys/room grids, weapons/attachments and all feature tools. Group/filter results by type, bounded token matching and result count; exact detail links, source uncertainty, map links only for reviewed grid data, existing relevant planning links. Ctrl/Meta+K opens search unless composing/modified; visible button and keyboard-native result links. No invented location or silently exposed spoiler data. Private profile data not indexed.
FR004 Return journeys preserve allowlisted filters/sort/expanded groups and scroll, with bounded session-only state and stable same-origin return links. Public detail links carry no query/private note contents. Existing dirty-draft navigation guards retain authority. No cross-origin private synchronization or broad navigation interception.
FR005 Map toolbar provides Search/Layers/Routes/Trackers plus Advanced and reset layout; single shared selection inspector mirrors the existing authoritative popup and closes/replaces cleanly, selected marker highlighting. Existing popup actions remain authoritative. Resizable/collapsible inspector persists only bounded local display preferences, clamped on resize; mobile bottom sheet and Escape/return focus. Existing draggable menus preserved; advanced source/maintenance controls stay available.
FR006 Dedicated Missions entry reuses existing source/progress semantics and spoiler guards, includes DMZ Orders/story and preserves upgrade separation. Complete end-to-end tests for Home→Upgrades→requirements/material references→progress/report→return; Home→Missions→requirements/source→manual progress→return. Also keys/packing/map, weapon/detail/attachments, map/route/tracker and missing-service/storage/back/refresh/mobile/keyboard cases.
FR007 Read-only local service availability is checked only on explicit Check services, fixed loopback allowlist, short deadlines/cancel, states reachable/unavailable/unchecked (not a proof of app health). No auto-start/OS schedules/network collection. Dashboard read-only summaries validate saved records, use bounded reads without initializing profiles, preserve uncertainty and expose retry/error; pins/recents display preferences separate from progress. Existing profile/armory/map/key bytes unchanged by navigation/search.

Non-goals: merge app databases/origins, new game facts, automatic progression, road accuracy certification or deployment. Existing tools are reused, with full functional regression and independent review. Manual pinned Spec Kit full-cycle fallback; no automated skill execution claimed.
