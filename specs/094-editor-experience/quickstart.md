# Quickstart

Run the existing local author service (npm run author). Open Edit page on an Order/item. Use Content/Layout/Photos controls and click preview sections to select them. Review changes; explicitly Save or Save & refresh. Saved files and refreshed reader have independent statuses. Revisions restore into a draft; checkpoints protect unfinished work across browsers. Public accounts remain future work.

Feature094 is implemented and locally verified; see acceptance.md and the independent final-review.md for exact scope and receipts. See contracts/editor-tools.md for local-only recovery/history/refresh boundaries.
