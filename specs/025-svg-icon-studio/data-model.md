# Data model
IconAsset gains optional design: IconDesign. Existing id/base64/width/height/description/rightsDeclaration remain unchanged; id is PNG SHA256, no separate unbounded SVG string. Version1 recipe exact fields: version1, frame(pin/circle/square/diamond/shield/none), symbol from original local enum, background/foreground/border six-digit hex colors, borderWidth integer0..4, symbolSize integer16..32, rotation integer0..359, label empty or1..3ASCIIalphanumeric. Fixed64x64 viewBox,256px sanitized savedPNG; title is icon description <=200chars, escaped on SVG export. Generated rights declaration identifies locally composed design.

Saved immutable content identity; Edit a copy→draft→Save variant. Identical PNG reuses existing IconAsset without overwriting recipe or references. When a matching raster-only asset lacks a recipe, attach the validated new recipe while preserving its image, description, ID and references. Cancel never commits; async work guarded by revision and cancellation. Optional design strict validation on every workspace restore/prepare; unknown fields/enums/versions/numbers rejected. Old backups have no design and remain valid. Recipes preserved in private backups; external-source icons untouched.
