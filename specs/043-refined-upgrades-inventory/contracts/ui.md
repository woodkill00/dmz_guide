- Owned blank=unknown;0=known empty; invalidrawstring remains recoverable. Reserve is independently editable and never silently reduced. Currency/non-count units keep identity/unit labels and separate totals.

- Details inline, maxoneexpanded row, close returns focus withoutscroll. Source evidence available on demand; criticalblocked/unknown/versionconflict remains in row/banner. Existing purchase/progress native dialogs keep the same confirmation/data-loss/privacy contracts.
