# Validation quickstart

Use a writable source checkout, Node 22+, npm ci. Run npm run check and npm run format:check. Build then npm start; open an item detail and follow both contextual actions to local-start guidance. No author server should be contacted until clicking the local open link.

Run npm run author separately. Use the explicit local link (or append the shown suffix to the printed custom-port address). Confirm exact catalog ID/record ID, focused field or image control and same-record return. Edit a label, validate/review/save with a new content version, then return to saved preview. Add an original rights-cleared fixture picture, replace primary and add additional picture; ensure another record sharing old primary is unchanged. Try canceling prepared image and leaving with unsaved work.

Run npm run test:studio; hosted CI runs Chrome on Windows/Linux and npm run test:studio -- --engines on Firefox/WebKit. Browser suite includes isolated copied-checkout saves and rebuilt pixel checks. Review responsive screenshots independently. Record exact command results and blockers in acceptance.md; do not bypass unavailable browser sandbox.
