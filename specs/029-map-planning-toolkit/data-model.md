# Contract
Optional Workspace.fieldGuide version1: tracking[], duplicateDecisions[], routes[], roadGraph|null, gameplay{enabled,largeMarkers,favoriteCategories[],savedQueries[]}, density:boolean. Source-bound decisions/ref marks contain identity, no source payload. Tracking requires immutable reference and current capture signature, date/evidence for owner confirmed. Route waypoint union {kind:record,key,identity} or {kind:manual,id,x,y,label}; source labels/positions resolved transiently, stale source changes reported. Owned generated geometry remains owned; local seed not copied into backup by default.
Graph format kind dmz-road-network/version1/mapId hajin/coordinateSpaceVersion hajin-official-v1-4096; name/attribution/verification unverified or observed; nodes{id,x,y}, edges{id,from,to,direction both/forward,blocked,points[[x,y]...]}; endpoints must match nodes, no zero-length/unknown/duplicate IDs, finite bounds and aggregate limits. Crossing lines not implicit intersections. Positive path length from geometry; no arbitrary imported costs/JS/URLs. Graph summary preview before persistence.
Share schema v1 center[x,y],zoom[-4,4],sources{id:boolean},categories{sourceID:{categoryID:boolean}}; registered website source IDs and source-scoped category IDs only,16KiB input bound; no private values. Unknown/private source or category IDs, unknown fields, or unavailable target captures produce an explicit invalid/unavailable preview with Apply disabled; nothing is silently dropped.
