# Built-in specification quality checklist

Maintained by specify/clarify; 2026-10-26. Scope is artifact quality, not runtime acceptance.

- [x] User journeys have priorities, independent tests and acceptance scenarios.
- [x] Functional requirements identify observable behavior and evidence boundaries.
- [x] Success criteria are measurable and linked to planned verification.
- [x] Assumptions, deferred scope and real external dependencies are explicit.
- [x] No invented game facts or unresolved placeholder requirements.
