# Tasks: Multi-source map workspace

Input: spec.md, plan.md, research.md, data-model.md, contracts/workspace.md. All boxes intentionally open: no runtime implementation is claimed. Tests are required by FR-013 and SC-001..006. Paths below are repository-relative. Serialize shared workspace/map integration; no parallel markers are used.

For each task, first write the named failing contract/behavior tests, then implementation, then run them. All validations must implement the quoted contract constraints: "JSON depth16", "IDs128 chars", "titles200", "notes4,000", "point" geometry only, "acceptance=pending/accepted/withdrawn, freshness=current/stale". T001 covers input enums/fields; T002 and T009 enforce the exact20MiB backup-projection admission budget; T008 covers "32 custom icons", "2MiB input/icon", "8MiB sanitized icon total", "2048 per axis", "4,194,304 pixels", "decode5s", "output<=256 per axis PNG". Count maxima are jointly subject to serialized-byte limits, not simultaneous guarantees.

## Dependencies and delivery boundaries

US2 uses synthetic or explicitly authorized snapshots and never requires prohibited acquisition. Real provider automation is deliberately not an implementation task: permission, parser schema and coordinate evidence require a future reviewed scope update. Independent checklist approval concerns definition quality only; tasks remain open until actual implementation evidence exists.
