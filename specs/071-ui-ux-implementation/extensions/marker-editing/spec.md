# Marker editing from selected details

US5 extension,2026-11-06. User authorizes an Edit button in the selected marker information, editing all user content fields and saving locally. E1: direct Edit for loaded/restored source, reviewed and own markers. E2: reuse full point editor (title/kind/category/X/Y/notes/evidence/floor/build/verification/icon/metadata/screenshots/geometry); immutable identity, source capture and timestamps remain provenance. E3: source/review changes save as a single linked owned override; raw captures/entities remain unchanged and their original marker is suppressed. Repeat edits update the same point, deleting it restores the source. Source refresh must not overwrite edits. E4: Save validates/bounds and uses existing transactional/conflict/failure handling; Cancel and guarded departure never save. E5: edited values survive reload/backup, map/search reflect them without duplicate originals, parent source masks still control overrides. E6: retain stable selected-details behavior, keyboard access and compact layout. No automatic provider edits or external publication.
