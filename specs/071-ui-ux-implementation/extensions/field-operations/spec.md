# Local field operations
User-approved scope: screenshot imports (not screen capture), stash/carried separation, post-run reconciliation, inventory journal/undo, guide-to-map collection handoff and private discovery records with optional pictures. Account/API assessment follows local implementation/testing; no credentials requested or account linking simulated.

FO-1 Screenshot upload/paste uses bundled local OCR, bounded raster decode and canonical name matching. Show raw recognition, confidence, ambiguous candidates and explicit editable mapping/counts. Never apply OCR silently. Counts are absolute for a selected pool; unseen items remain unchanged. Repeated pictures/overlapping ambiguous rows cannot double stock. Record import fingerprints atomically with quantities.
FO-2 Existing inventory remains FOB stash and the current forecast input. Carried stock is separate and excluded from FOB requirements. Transfers conserve total stock; unknown stock cannot be silently decremented. Individual/batch transfers and returning carried stock are explicit reviewed operations.
FO-3 Stage extracted/lost/spent/crafted corrections per pool and item, show before/after then apply one revision-bound transaction. Craft rows are player-reported adjustments, not automatic recipe execution or mission completion.
FO-4 Opt-in journal starts with first field operation/explicit enable; subsequent quantity saves across existing pages are journalled atomically in storage. Old profiles remain accepted. Preserve missing versus zero. Undo verifies current affected values and exact content binding and never clobbers intervening edits. Bound history and retain existing previous-snapshot recovery.
FO-5 Collection handoff exports a bounded versioned plan with visible shortages/named areas, never account secrets. Explicit map import is reviewed and can highlight known positions or create a new route through existing road planner. Unknown places stay unplotted. No silent source masks/inventory writes across origins.
FO-6 Discoveries bind item/date/quantity/container/location/notes and optional validated local raster photo. They are private observations, never promoted to verified game facts. Complete field backup includes journal/carried/discoveries/photos, validates before restore, supports review and failure recovery.
FO-7 Compact accessible dedicated Field desk page linked from navigation, FOB, Inventory and item pages; ordinary inventory editing and existing trackers keep their save owners. No screen capture, injection, memory reads, gameplay automation or promised account sync.

Clarifications resolved by conservative defaults: stash scans never include carried stock; imported counts replace only checked mapped rows; duplicate quantities require a choice rather than summation; discoveries use existing named locations or player text without inferred coordinates. Catalog rebind is required before mutations. All edits retained on failed saves and dirty-navigation guards apply.
