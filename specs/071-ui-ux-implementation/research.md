# Research decisions after final stress roundtable

Scope: implementation readiness, not new visual direction. Reuse070primary-source research (W3C/Fluent/Carbon/Esri) and reviewed design. No claim that agent agreement proves player usability.

1. **Decision:** height/intrinsic-content fallback overrides width docking. **Rationale:** actual070synthetic probe at320×568/200%root text produced380pxbodywidth and route/task intersection;844×390root200 had inadequate vertical allocation. **Alternative rejected:** more absolute offsets/min-height patches. Use explicit Map/Task views and normal scrolling when readable simultaneous panes do not fit. Root scaling is not browser zoom.
2. **Decision:** existing transactional controllers own saves; UI results are generation/context bound. **Rationale:** actual070Save→Find→Discard during650msdemo callback caused a null-status error and revived discarded name. **Rejected:** timer completion as durable save or blanket promise of cancel/rollback. Existing noncancelable commits remain noncancelable and require truthful recovery.
3. **Decision:** first departure intent is frozen and revalidated after confirmed Save. **Rationale:** repeated links or stale destination must not retarget a pending action. **Rejected:** silently replacing destination while a guard is open. Same-task click leaves draft untouched; new-tab links do not count as departure.
4. **Decision:** view cache8includingactive, detail in originating entry; drafts/operations stay outside its ownership. **Rationale:** bound memory without losing Back anchor through LRU eviction or discarding writes. **Rejected:** unbounded task history or generic private-draft serialization.
5. **Decision:** route actions atomically bind route/revision/token and retain current coordinate/write guards, but do not gate manual Reached on road solving. **Evidence:** current field-guide-ui.ts setReached requires resolveWaypoint(stop).point and normalguard; HUD disables unresolved Show/Reached. **Rejected:** blanket disable during road failure/recompute or changing domain semantics to allow unresolved progress.
6. **Decision:** one concise issue summary per owner with linked details, never stacked raw errors. **Rationale:** route/source/save failures together can erase terrain and controls. **Rejected:** hiding failed saves in transient toasts or overwriting them with ready state.
7. **Decision:** exact registry+family scope matrix. **Evidence:** generated currentregistry has77entries:28guide,48map,1studio; map count includes main/safe/help plus45tool targets. Older docs/reviewer reference76is superseded by current generated list. **Rejected:** vague 'allfeatures' without mapping; distinguish native/map/private search/backup scopes.
