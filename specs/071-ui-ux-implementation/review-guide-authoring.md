## What works and should remain

Home has one clear public-reference search, four recognizable workspaces and small secondary pin controls. The Guide hub states that coverage remains unknown. The weapon directory retains a real list and exact detail links, readable source-tagged statistics and separate workbench navigation; official weapon figures are not treated as proof of game mechanics.

Studio prominently separates checkout-file authoring from browser-private player records, requires review before repository Save and says it does not commit or push. Manager identifies the local checkout, states that private loadouts/screenshots are not read, separates staged checks from Apply and explains the `*WZ` marker as the guide's MW4 Multiplayer fallback, untested in DMZ. The inactive-proposal state does not imply an update has been applied. These scope statements remain visible in narrow layouts and should survive later density changes.

## Limits

This review did not run a performance benchmark, validate collected weapon numbers, inspect the full current mission/catalog coverage, exercise all authoring/import/save recovery branches, or replace the original Studio/domain preservation suites. It did not use a physical device, a screen reader, real mobile keyboard, native 200/400% browser zoom or actual BFCache. The manual acceptance items and default-promotion decision retain their independent owners.
