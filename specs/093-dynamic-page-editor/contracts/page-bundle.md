# Page-document bundle v1

Envelope has exactly `{format:"dmz-page-document-bundle",version:1,mode,target,base,document,assets}`. mode=`self-contained|references-only`; target/document follow document-format.md and must agree. base has exactly `{semanticFingerprint,canonicalRevision,documentRevision}`: fingerprint lowercaseSHA256, revisions nonnegative safe integers. assets is a unique array of exactly the distinct image IDs referenced by document (<=9 in v1, additionally subject to existing32asset portable ceiling).

Each entry has exactly `{metadata,data}`. metadata has exactly `{id,mime,sha256,bytes,width,height,rightsHolder,license,sourceUrl,attribution,redistributionAllowed}` using existing pack.schema.json asset rules except no filesystem path: namespaced ID<=100; MIME PNG/JPEG/WebP; hash lowercaseSHA256; positive safe byte count<=2MiB; dimensions1..2048 and pixels<=4194304; holder/license nonempty<=200; attribution nonempty<=1000; safe sourceURL<=2000 with current http/https validation; redistributionAllowed=true. Local author generates managed paths after validation, never imports arbitrary paths.

Self-contained mode requires canonical padded RFC4648 base64 data for every asset; exact size/hash/MIME/decode/pixel checks before preview, plus current source/visible/embedded-metadata export review. Combined binary<=8MiB, decoded pixels<=16777216, envelope<=20MiB. JSON depth14/nodes20000; only the explicitly bounded base64 field gets its encoded-byte string allowance, not ordinary text. Document's own256KiB/12000node/depth10 rules checked independently. Missing pixels or excess size reject complete export without truncation.

References-only mode requires data=null and visible label Pictures not included; no complete-offline-restore claim. Import resolves ID/hash against permitted current library assets, lists missing/mismatched entries and may stage an unsaved placeholder preview. Repository save stays blocked until all references resolve. Missing bytes never clear saved placements.

Target/base mismatch opens comparison/selection preview; no silent application. Equal asset ID with different hash requires explicit reviewed new-ID mapping, never shared-byte overwrite. Restoring old content previews stable-anchor changes and preserves required deleted-anchor notices. No new canonical facts or record ownership inferred. Profile/inventory/acquisition/progress and unknown formats are rejected.

Only registered permitted author library pictures are reusable. Ignored local weapon/camo/key caches are not tracked author assets and are never auto-copied into repository files or bundles. Existing managed projections keep their current local-only viewer routes. Turning downloaded art into new tracked assets needs separate verified redistribution permission and explicit ingestion outside this feature; screenshot/local-use permissions are not extrapolated.
