# Orders guide screenshots

## Outcome
The 26 distinct COD Central Order-task screenshots appear on the 17 matching Hajin/X01 Order pages, locally bundled and readable without visiting the source site. Every image has an informative description, source link and rights attribution. Existing Order text, progress and audit links stay intact.

## Requirements
- **FR-001:** Import exactly the 26 audited guide screenshots, excluding duplicate lightbox sizes, introductory illustrations, reward icons and unrelated article images.
- **FR-002:** Bind each screenshot to the matching official-starter Order ID, including same-named Orders from different chapters. No image may appear in an unrelated catalog.
- **FR-003:** Keep each image under the catalog byte/pixel limits, validate WebP bytes and hashes, and record origin, rights holder, permission basis, source URL and attribution in public metadata.
- **FR-004:** Present responsive, accessible Order picture galleries with meaningful alternative text and source attribution. Existing missions without screenshots remain unchanged.
- **FR-005:** Verify all image counts, binding, build output, browser display at desktop/mobile width, source links and full regression checks.

## Source and rights
The project owner explicitly confirmed permission on 2026-11-16 to redistribute COD Central guide screenshots in this public repository. This is an owner assertion, not an independently verified COD Central license. COD Central's published data license does not cover screenshots. The imported scope is screenshots only; reward icons are excluded.

## Boundaries
No remote hotlink dependency at runtime, no provider prose copied, no false game verification. Source screenshots may contain game art; attribution does not change ownership of underlying material.
