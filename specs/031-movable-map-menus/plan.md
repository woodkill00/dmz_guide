# Design
Use one mountMapMenuLayout controller in src/map/menu-layout.ts. Register fixed overlays after workspace mount, discover late dynamic overlays with a bounded selector set and MutationObserver. Prepend separate handles; wrap standalone launcher buttons and dynamic tracker/gameplay content without changing their original IDs. Stable external handles survive replaceChildren redraws without focus/capture interruption. Save independent normalized x/y positions in a fixed-key localStorage object; validate every entry and guard access. CSS left/top overrides only after a menu is moved. ResizeObserver observes map and menu dimensions, requestAnimationFrame coalesces layout work and ignores zero-sized/hidden items. Cleanup disconnects observers, pointer capture and listeners on HMR.
Pointer capture owns handle gestures only, propagation stops before Leaflet; cancel restores prior position and persists only completed gestures. Keyboard arrows and Home provide equivalent operations; double-click resets. Keep initial responsive CSS until user movement, and constrain overflow with border-box sizing.
No schema migration or IndexedDB writes. Existing HUD collapsed preference remains independent. Verify with synthetic browser fixture plus production type/build, repository checks and existing regression/engine flows. Independent requirements and implementation review required by AGENTS.md. No installed workflow hooks or optional extensions are assumed.
