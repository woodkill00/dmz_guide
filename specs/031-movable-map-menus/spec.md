# Movable map menus
2026-10-29. Local viewer display feature.
User story: Move small floating map menus away from the area being viewed and resume the same arrangement after reload.
FR001 Give these map overlays separate labelled drag handles: navigation controls, map-key/fullscreen controls, My workspace launcher, Routes launcher, waypoint tracker (expanded or minimized), gameplay toolbar. Dynamic overlays must retain the handle across redraws. Keep existing action buttons functional; dragging must not pan the map or trigger actions. The docked full map-key sidebar, modal editors and map-anchored POI popups stay in their existing layout.
FR002 Pointer/mouse/touch handle movement and focused-handle arrow movement (10px; Shift 1px) move the overlay; Home or double-click restores its default position. Escape/pointercancel cancels an unfinished drag. Handles describe controls, expose visible focus and work without precision gestures.
FR003 Save bounded normalized positions per overlay in a versioned local display preference, separate from IndexedDB workspace. Reload/recreation restores positions. Reject malformed/nonfinite/out-of-range stored entries. Storage failure keeps current-session movement usable. Clamp the whole overlay inside the map after resize/fullscreen, show, or content growth; oversized content scrolls within available space. Default placements remain responsive until moved. Never change map view, masks, routes, progress or workspace revisions.
FR004 Document coverage/reset/storage semantics. Verify actual drag, keyboard, cancel, reload, dynamic tracker redraw/minimize, resize/mobile containment, hostile preferences/storage failure, unchanged workspace and existing tests. No new dependencies, assets, provider collection or remote writes.
SC001 Move each listed overlay, use its action normally, refresh and find it in the saved relative location. Reset returns to responsive defaults.
SC002 Mobile resize cannot strand a handle outside map bounds; progress/minimize rerenders preserve position and focus. Tests use synthetic content; physical touch/screenreader evidence is not claimed.
Clarification: this request concerns small map overlays; fullscreen modal editing and geographic popups retain their established semantics. Preferences are browser-local and excluded from private map-data backups.
