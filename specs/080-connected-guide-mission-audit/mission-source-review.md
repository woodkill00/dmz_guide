## Wider source comparison staged for review

COD Central publishes a 24-row Hajin page table with three names per row and a separate five-page X01 chapter. DMZTracker's current directory lists 66 linked Order rows, mixing fixed page labels and chapter labels. Their coverage therefore differs and cannot establish a common complete denominator. COD Central explicitly warns that chapter choices can change a player's displayed page order, including later pages. The catalog must bind any further chapter mission by stable identity before assigning a fixed `orderPage`.

The sources also vary in spelling (`Jail Break` versus `Jailbreak`) and omit different story-ending rows from the directory view. The article's second-page Boss Board statement conflicts with the tracker's Crackshot unlock claim. Each such claim stays in the editorial review queue; no alias, reward, prerequisite, map location or effect is inferred from a name match alone. The next admission pass should compare each candidate's detail page, build/date, steps and linked evidence, then bring in small reviewed groups with exact tests.
