# UI contract
Planner Boss checklist: saved-target summary, query/type/status filters, paged rows, Record kill/Undo latest/settings/history/source links and optional Show location. Empty state exposes local boss roster preview and manual target form. Roster preview lists names/types/diffs without saving; Apply(expected revision) or Cancel. Global processing cancel/supersession prevents late previews. Logs/settings preserve dirty/revision/epoch/quota recovery. Derived completion is explicit text, not a checkbox that silently rewrites history. Pinned rows appear in compact Match mode with guarded +1; no live detection. Private export/backup includes checklist; public links/packs exclude it.
