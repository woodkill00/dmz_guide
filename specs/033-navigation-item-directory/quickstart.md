# Verification journey
1. Build and start the guide. Open Items, select All packs, search and sort, then follow Details, Edit and Remove. Verify the exact record and source catalog identities.
2. Start local Content Studio and open the removal target. Referenced records must be blocked; Cancel must leave the draft unchanged and return focus to Preview record removal.
3. An unreferenced synthetic draft item can be removed only through explicit preview and confirmation. Repository files remain unchanged until a separate validated save.
4. Make a harmless unsaved edit and decline a catalog switch. The draft must be retained.
5. Open Site map and Local map workspace through a nondefault catalog. Navigation retains the catalog, but the external map link carries no private context or catalog query.
6. Repeat with keyboard at 320px and 200% text. All item rows remain readable without JavaScript. Spoiler titles remain protected.

Browser execution and visual inspection remain required acceptance gates; writing these scenarios does not mean they passed.
