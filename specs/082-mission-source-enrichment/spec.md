# Mission source enrichment

## Outcome

Readers can see the recorded task steps on each mission page and review source-reported rewards for each Hajin chapter roster. The mission directory stays compact; rewards are disclosed on demand. Existing mission IDs, audit links and private progress remain stable.

## Requirements

- **FR-001:** Show all non-spoiler-protected recorded task steps on the individual mission detail, and an explicit unknown state where steps are absent.
- **FR-002:** Show page-level rewards for all 24 Hajin rosters, never as individual mission grants or verified current-build unlocks. Variable chapter order stays marked as variable.
- **FR-003:** Attribute reward reports to COD Central, DMZ Radar and, where covered, Game8; preserve source and review date. Link the original pages.
- **FR-004:** Provide mission directory and audit navigation on detail pages; maintain spoiler boundaries, X01 separation and responsive keyboard operation.
- **FR-005:** Test roster alignment, detail rendering, unknown steps and project regression checks.

## Boundaries

No gameplay automation, invented unlock effects, copied provider images or long verbatim prose. Conflicting and incomplete mission records remain flagged for manual review. Reward labels are source reports, not player progress or executable catalog effects.
