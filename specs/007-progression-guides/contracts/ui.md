# UI
featurePages(packs) exports native progression route. Required common loader IDs pack-select,pack-note,save-status,error,export-current-profile. Track/search filters, reveal/hide spoilers button, each objective status select+prerequisite list, guide links, source/coverage labels. Reset named pack confirmation captures revision, direct export and settings recovery link remain available.
All cross-links/prerequisite labels/effects mask spoiler records before reveal; document title generic. Reveal/hide retains focus on same toggle and rerenders current results to remove text. Reset focus enters confirmation, cancel returns to reset trigger. Tests include stale-tab reset conflict preserving current profile.

Filter IDs are progress-track, progress-query, progress-source, progress-status (evidence), and progress-state (manual). Clear filters resets all five. progress-count announces matches without inventing a coverage denominator. Sources show title, safe URL when available, publication/review dates and support text; record scope/content version stays explicit. Data mutations and pack switching are disabled during a pending save; status changes re-render prerequisite states and restore focus to the changed control or active filter.

Previous/Next controls paginate 50 records; the live result count distinguishes displayed range from matching total. Oversized evidence/dependency previews disclose truncation and retain the pack-qualified detail route. Source-choice and spoiler-dictionary limits show explicit notices, never silent truncation. Search covers only safe visible primary title/body/track fields, not raw references or hidden metadata.
