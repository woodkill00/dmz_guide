# Quickstart

Use `npm run local` for the unified site. Content gaps: `/quality/`; mission sections/X01: `/missions/audit/`. Run `npm run audit:content` for the scoped gap report and `npm run test:reliability` for isolated three-engine tracking/return checks. Other commands stay in package.json. Exact results and limits are in [verification.md](verification.md).

Preservation is private under ignored `.local/private-backups/`. Do not add this directory to Git or run restore/reset. Dedicated recovery verification is the final separate follow-up after this feature.
