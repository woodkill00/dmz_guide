# Routes and state ownership

Implementation refinement: `#owned-attachments` is the compact ownership checklist tab. Reference subanchors also include `#gunsmith` and `#codmunity-data`; `#camo-sources` opens the camo tab. A mastery deep link activates the matching mastery view before opening its challenge.

Canonical `/armory/` and `/armory/<catalog-weapon-id>/` accept tabs acquisition, camos, builder, compare, evidence, reference, backups; default acquisition. Legacy `/armory/workbench/` preserves those recognized tabs (including its previous default compare). `/armory/acquisition/?weapon=ID#weapon-ID` maps to `/armory/ID/#acquisition`. `/armory/camos/ID/#CAMO` maps to `/armory/ID/#camo:CAMO`; this opens the camos tab and matching details. Camo overview maps root #camos; shared camo selection uses the current/first catalog weapon and shared completion keys, not a fabricated new weapon. `#attachments`, `#patch-history`, `#weapon-intel` select reference and retain anchor scrolling. Unknown/repeated selectors are ignored with a readable notice; preserved unrelated query parameters are inert. No redirect destination accepts a remote origin. Alias pages show the exact native destination link without JavaScript; dynamic query/hash translation requires JavaScript and is explained there.

Every unified page mounts workbench once. Camo adapter delegates checkbox edits to workbench mutate(editCamoCompletion); extraction/blueprint edits delegate to mutate(editAcquisition). No second createCamoSession/acquisition workspace is mounted. Single revision and pending/unsaved flags gate every private writer, including camo controls. Failure leaves the existing unsaved candidate available through shared Backups export/retry/reload, with visible error; no other write may replace it. Public tabs/details remain readable after storage failure.

Existing beforeunload protects build/evidence drafts, pending writes and retained candidates. Switching tabs retains DOM/values, including selected attachments; weapon links perform normal navigation and trigger departure protection. Reload Saved explicitly confirms discarding drafts via the existing load path. Tests must hold one save pending and assert embedded controls lock; simulate quota/stale revision and assert candidate retained, exportable and subsequent writer refused; cancel departure from a dirty build and verify its fields persist. Shared camo completion is asserted on a second weapon page after reload.
