# Research and existing behavior

Read `src/ui/feature-registry.mjs`, `docs/home-navigation.md`, `docs/field-operations.md`, `docs/collection-workbench.md`, `docs/keys.md`, `docs/local-map-workspace.md`, `docs/field-command.md`, `docs/armory-workbench.md` and feature071 implementation status on 2026-11-11. Existing features include cross-page search, field-desk OCR/history, key trips, safe routing, source updates, weapon evidence and compact shells. Proposals extend these owners rather than duplicate them. `docs/ui-ux-redesign.md` already targets compact layouts and stable map selection;073 must verify/complete those adaptations, not claim them as new merely by styling.

[WCAG 2.2](https://www.w3.org/TR/WCAG22/) and [WAI's new-in-2.2 summary](https://www.w3.org/WAI/standards-guidelines/wcag/new-in-22/) support visible focus, minimum pointer targets and non-drag alternatives. The project design target of 44px for primary touch actions is stronger than WCAG's conditional 24px minimum.

Activision's [account guidance](https://support.activision.com/articles/managing-your-activision-profile) does not establish an approved DMZ stash contract. The local future-import adapter must remain file-only and disabled for unsupported schemas.
