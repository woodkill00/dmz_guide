# Project glossary

These definitions describe the guide's concepts, not new verified game facts.

- **Public content**: source-attributed reference records distributed with the guide.
- **Private player state**: locally saved inventory, progress and goals belonging to the user's browser workspace; separate from repository content.
- **Content pack**: a versioned collection of reference identities and relationships. Similar names across packs do not establish identical identities.
- **Inventory quantity**: recorded owned stock for a particular identity; absent or unknown stock is distinct from an explicit zero.
- **Required quantity**: demand attributed to the selected unfinished goals under the planner's supported rules and scope.
- **Missing quantity**: the outstanding amount after applicable saved stock and planning rules; unknown demand cannot be silently converted to zero.
- **Recipe**: a recorded relationship between outputs, ingredients, quantities and applicable conditions; its existence does not itself grant ownership or prove current game availability.
- **Blueprint ownership**: a player's recorded unlock/ownership state, distinct from a recipe definition and from the ability to print an item under particular conditions.
- **Weapon manual ownership**: the recorded owned-manual flag, distinct from the manual extraction counter.
- **Manual extraction progress**: the separately tracked extraction count toward the guide's recorded target; it is not ordinary inventory stock.
- **Order**: a mission grouping/page with objective parts and progress. Hajin and X01 scope must remain explicit.
- **POI**: a mapped point of interest with identity, position, type and provenance.
- **Source marker**: a provider's observation retained for comparison; multiple source markers can refer to a combined location.
- **Combined location**: a reconciled map location retaining source relationships; it does not discard provenance.
- **Active feature**: the owning Spec Kit directory selected by explicit override or machine-local pointer; a Git branch alone does not select it.
- **Pilot**: an isolated fictional exercise of actual agent behavior; fixture generation and static validation alone are not acceptance.
